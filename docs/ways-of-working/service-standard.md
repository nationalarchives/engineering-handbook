# Service standard

- You MUST follow [GOV.UK Service Manual](https://www.gov.uk/service-manual)
- You MUST follow the [Technology Code of Practice](https://www.gov.uk/guidance/the-technology-code-of-practice) from GOV.UK
- You SHOULD follow the [twelve-factor methodology](https://12factor.net/)
- You SHOULD use a [Post/Redirect/Get](https://en.wikipedia.org/wiki/Post/Redirect/Get) pattern when working with `POST` requests
- You COULD follow [the GDS Way](https://gds-way.digital.cabinet-office.gov.uk/)
- You COULD follow the [Resource-oriented Client Architecture](https://roca-style.org/)
